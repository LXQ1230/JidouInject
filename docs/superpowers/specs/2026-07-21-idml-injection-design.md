# IDML 句读结果回注工具 — 设计文档

> 2026-07-21 | 待审阅

## 一句话总结

把句读结果里的文字和「。」写回 IDML，排版样式原封不动。

---

## 一、输入 → 输出

```
275导出.idml   +   275从ID中导出文字_WD句读结果.md
        ↓
275导出_WD注入.idml
```

---

## 二、不能变的东西（铁律）

1. **排版不能变** — 字体、字号、颜色、间距、对齐方式，全部保持原样
2. **段落不能变** — 原来哪里换段，结果就在哪里换段
3. **原文不能动** — 原文汉字一个字都不能增、删、改
4. **只做两件事** — 把旧标点替换为「。」，在句读规则指定的位置插入「。」

---

## 三、处理步骤

| 步骤 | 做什么 | 通俗解释 |
|------|--------|----------|
| ① 拆开 | 解开 IDML（它是个压缩包） | 就像解压 zip 文件 |
| ② 读取 | 从里面把每个字拿出来，记下每个字的样式 | 记住每个字穿什么"衣服" |
| ③ 验证 | 确认 IDML 里的原文字数 = 句读结果里的原文字数 | 字数对不上就报错停止 |
| ④ 对齐 | 把句读结果的字和 IDML 的字一一对上 | 确保每个字去正确的位置 |
| ⑤ 写入 | 字穿回原样式，新「。」穿"句号样式" | 换字不换衣服 |
| ⑥ 封裝 | 重新打包成 IDML | 压缩回去 |

---

## 四、特殊情况的处理

| 遇到什么 | 怎么办 |
|----------|--------|
| 句读结果里的空行、空格 | **忽略**，段落怎么分全听 IDML 的 |
| IDML 里的旧标点 | **清除**，换成句读结果里的「。」 |
| 新增的「。」用什么样式 | 用 IDML 里已有的"句号样式" |
| IDML 里的技术标记（非文字内容） | **原样保留**，不动它 |
| 字数验证不通过 | **报错停止**，不生成文件，防止产出坏结果 |

---

## 五、使用方式

**命令行**（在终端输入）：
```
python inject.py --idml 275导出.idml --result 275从ID中导出文字_WD句读结果.md
```

**拖拽**：把 idml 文件和 md 文件一起拖到脚本图标上，自动执行。

两种方式都支持。

---

## 六、适用范围

- 不只是 275 和 461，以后所有同类文件都可以用
- 只要 IDML 和句读结果配套，就能处理
