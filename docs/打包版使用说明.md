# IDML 句读回注工具 — 免 Python 环境使用说明

> 本说明面向目标电脑（无 Python 环境）。程序为**单文件绿色版**，
> 复制 `IDML句读回注工具.exe` 到任意文件夹即可使用，无需安装任何软件。

## 一、两种使用方式

### 方式 1：拖拽（推荐，与旧版 .bat 习惯一致）

1. 准备好两个文件：
   - **IDML 文件**（如 `497导出.idml`）
   - **句读结果文件**（.md 或 .txt，如 `497句读结果.md`）
2. 把这两个文件**同时**拖到 `IDML句读回注工具.exe` 图标上松手。
3. 自动弹出黑色命令行窗口，显示处理进度；完成后按回车键关闭。
4. 输出文件生成在与 IDML 同目录：`{IDML名}_WD注入.idml`
   （例：`497导出.idml` → `497导出_WD注入.idml`）。

> 只拖了 1 个文件会提示错误——必须两个文件同时拖入。

### 方式 2：图形界面（双击运行）

1. 双击 `IDML句读回注工具.exe`，打开图形窗口。
2. **单文件回注**：分别点「浏览…」选择 IDML 与句读结果，
   输出文件留空则自动生成（与 IDML 同目录）；点「开始回注」。
3. **批量处理**：把多个「同经号」的文件对放进同一个文件夹
   （文件名以数字经号开头，如 `497导出.idml` + `497句读结果.md`），
   点「批量处理…」选择该文件夹，程序自动配对逐个处理。
   输出生成在所选文件夹的 `output\` 子目录下。
4. 处理日志实时显示在窗口下方，出错会弹窗提示。

## 二、文件命名约定（批量模式必需）

| 文件 | 命名要求 | 示例 |
|---|---|---|
| IDML | 以数字经号开头，`.idml` 结尾 | `497导出.idml` |
| 句读结果 | 同经号开头，`.md` / `.txt` 结尾 | `497句读结果.md` |

- 经号相同的 IDML 与句读结果自动配成一对。
- 自动排除：`*_WD注入*.idml`（上次的输出）与 `*_test*`（测试文件），可放心重复使用同一文件夹。
- 同名经号多个文件时：IDML 优先选含「导出」的；结果按文件名排序取第一个。

## 三、安全与覆盖规则

- **绝不覆盖**已有文件：输出文件已存在时自动加 `_v2`、`_v3` 后缀重命名。
- 单文件模式下若输出已存在，会弹窗让你选择：覆盖 / 自动重命名 / 取消。
- 输出文件不能与 IDML 源文件同一路径（防止覆盖源文件）。

## 四、常见问题

| 问题 | 处理 |
|---|---|
| 拖拽后黑窗一闪而过 | 不会发生——程序会在处理结束后等待按回车 |
| 提示「文件不是有效的 IDML」 | 该文件不是标准 IDML（可能被改名或损坏） |
| 提示「找不到对应句读结果」 | 句读结果文件名开头的数字经号与 IDML 不一致 |
| 杀毒软件误报 | 首次生成的 exe 可能被误报，添加信任即可（Nuitka 打包程序常见） |
| 处理大经书较慢 | 属正常现象，进度条会实时显示百分比 |
